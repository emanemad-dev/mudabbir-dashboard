# Mudabbir - Personal Finance Dashboard 💰

**Mudabbir** is a responsive personal finance dashboard built with **HTML and Bootstrap**.  
It helps you track your **current balance, income, expenses, recent transactions, and activities** in a clean and organized interface.

---

## 📌 Features
- Fully **responsive** layout for all screen sizes  
- Sidebar navigation with quick action buttons  
- Summary cards: **Current Balance, Income, Expenses**  
- Latest activities with color-coded indicators  
- Recent transactions table with category and status  
- **RTL support** for Arabic interface

## ⚡ How to Use
1. Open `index.html` in your browser (no server required).  
2. Navigate through the dashboard to view summaries, activities, and transactions.  
3. Fully frontend — no database or backend needed.
